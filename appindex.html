About This Project

This website is a visual demonstration of the Java-based Dating Application developed as a Capstone Project. The original backend uses Java classes such as UserAccount, Interest and DAO for storing and finding compatible matches. This GitHub Pages version demonstrates the interface using HTML, CSS and JavaScript.
